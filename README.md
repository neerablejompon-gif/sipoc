# ระบบติดตามและรายงานผลการดำเนินงานตาม SIPOC

เว็บแอปแบบไฟล์เดียว (HTML/CSS/JavaScript ไม่ต้อง build) สำหรับดูความเชื่อมโยงของกระบวนการ SIPOC
และติดตามแผน/ผลของแต่ละกิจกรรม ปีงบประมาณ 2570 (ต.ค. 2569 – ก.ย. 2570)

## เริ่มใช้งาน

```bash
python3 -m http.server 8000      # แล้วเปิด http://localhost:8000
```

หรือเปิด `index.html` ในเบราว์เซอร์โดยตรง หรือนำทั้งโฟลเดอร์ขึ้นเว็บโฮสติ้งแบบ static (เช่น GitHub Pages)

## ข้อมูลตั้งต้นจากไฟล์ SIPOC

`js/sipoc-data.js` สร้างจากไฟล์ `Sipoc (SE-AM ...).xlsx` 18 ไฟล์ใน repo (หนึ่งไฟล์ = หนึ่งหัวข้อ)
ได้ 18 หัวข้อ 762 กล่อง โดยเป็นกล่องกิจกรรม (คอลัมน์ P) 165 กล่อง เมื่อแก้ไฟล์ Excel ให้สร้างใหม่ด้วย

```bash
python3 tools/extract_sipoc.py *.xlsx -o js/sipoc-data.js
```

สคริปต์ (ใช้เฉพาะไลบรารีมาตรฐานของ Python) จะ

- เลือกชีตที่ **ไม่ถูกซ่อน** และมีหัวคอลัมน์ ผู้ส่งมอบ / ปัจจัยนำเข้า / กิจกรรมการทำงาน / ผลผลิต / ผู้รับบริการ
  ถ้ามีหลายชีต ใช้ชีตสุดท้าย และพิมพ์ชื่อชีตอื่นให้ตรวจ (ปัจจุบันข้อ 1.3 มีชีต "(เ)" และ "(ป)" ระบบใช้ "(ป)")
  เลือกชีตเองได้ด้วย `--sheet "1.3=(เ)"`
- ถอดข้อความจากเซลล์และกล่องข้อความ/รูปทรง รวมรูปทรงในกลุ่ม คำนวณตำแหน่งจาก anchor ของ Excel
  และจัดเข้าคอลัมน์ S/I/P/O/C ตามหัวคอลัมน์ (ถ้าไม่มีหัวคอลัมน์บางช่อง จะประมาณจากระยะห่างของหัวคอลัมน์อื่น)
- ตัดป้ายทางแยกในผังงาน เช่น yes / no / เห็นชอบ / ไม่เห็นชอบ / ปรับแก้ / ตัวเชื่อมหน้า "A" และหัวคอลัมน์ที่พิมพ์ซ้ำ
- อ่านชื่อกระบวนการ หน่วยงานที่รับผิดชอบ และวัตถุประสงค์จากส่วนหัวของชีต
- อ่านคอลัมน์ **ระยะเวลา / เป้าหมาย / ผล / หมายเหตุ** แล้วผูกกับกิจกรรมที่แถวใกล้ที่สุด
  เดือนในคอลัมน์ระยะเวลา/เป้าหมาย (เช่น "ส.ค.", "ก.ย. - ธ.ค.", "ไตรมาส 3", "ทุกเดือน") ใช้เป็น **เดือนแผนเริ่มต้น**
  ของปีงบประมาณ 2570 ส่วนคอลัมน์ผลเป็นข้อมูลอ้างอิงจากต้นฉบับ ไม่ถูกนำไปทำเครื่องหมายผล
- ใช้เส้นเชื่อม (connector) ใน Excel เมื่อผูกกับรูปทรงไว้ (เช่น ข้อ 1.4)

ตรวจผลได้ในแท็บ **ข้อมูลต้นฉบับ** รหัสกิจกรรม (เช่น `3.2-P04`) อิงเลขข้อและลำดับกล่อง
ถ้าแก้ไฟล์ Excel จนลำดับเปลี่ยนแล้วรันใหม่ ข้อมูลติดตามที่บันทึกไว้อาจจับคู่ผิดกิจกรรม

## ความสามารถ

| มุมมอง | ใช้ทำอะไร |
|---|---|
| ผัง SIPOC | ผัง S → I → P → O → C แยกตามหัวข้อ คลิกกล่อง P เพื่อแก้ไขข้อมูลติดตาม สีขอบบอกสถานะ ข้อความยาวตัดด้วย "…" (วางเมาส์ดูข้อความเต็ม) ล้อเมาส์เลื่อนขึ้นลง Shift + ล้อเมาส์เลื่อนแนวนอน |
| รายการกิจกรรม | ตารางแผน/ผลรายเดือนตามรูปแบบแผนปฏิบัติการ กิจกรรมละ 2 แถว (แผน/ผล) คลิกช่องเดือนเพื่อทำเครื่องหมาย/ยกเลิก ตรึงหัวตารางและคอลัมน์ชื่อกิจกรรม กรองตามหัวข้อ สถานะ และคำค้น |
| ข้อมูลต้นฉบับ | ข้อความที่ถอดจากเซลล์และกล่องข้อความของแต่ละชีต พร้อมตำแหน่งแถวอ้างอิง |

- ตัวเลขสรุปด้านบน: กิจกรรมทั้งหมด / เสร็จสิ้น / กำลังดำเนินการ / เกินกำหนด (เลยวันครบกำหนดและยังไม่เสร็จ)
- แบบฟอร์ม **แก้ไข / แนบไฟล์**: ชื่อกิจกรรม กระบวนการ ผลผลิต/หลักฐาน ตัวชี้วัด ปริมาณงานตามแผน/จริง หน่วยนับ
  ผู้รับผิดชอบ วันครบกำหนด สถานะ ผลการดำเนินงาน หมายเหตุ เดือนแผน/ผล และไฟล์แนบ
  (กิจกรรมที่เพิ่มใหม่ต้องบันทึกก่อน แล้วเปิดอีกครั้งเพื่อแนบไฟล์)
- **สรุปรายงาน**: ภาพรวม สรุปตามกระบวนการ งานเกินกำหนด และรายการที่มีผลการดำเนินงานพร้อมตัวชี้วัด พิมพ์ได้
- **ส่งออก CSV** (UTF-8 BOM เปิดใน Excel ได้): ทุกฟิลด์ของกิจกรรม เดือนแผน/ผล และชื่อไฟล์แนบ (ไม่รวมตัวไฟล์)
- **สำรองข้อมูล**: ดาวน์โหลด/นำเข้าข้อมูลกิจกรรมเป็น JSON เพื่อย้ายเครื่อง (ไม่รวมตัวไฟล์แนบ)

เครื่องหมายรายเดือนหมายถึง "มีแผน" หรือ "มีผล" ในเดือนนั้น ไม่ใช่จำนวนผลงานรายเดือน
ปริมาณงานบันทึกเป็นค่ารวมของกิจกรรม

## ข้อจำกัด

- ข้อมูลกิจกรรมเก็บใน `localStorage` และไฟล์แนบเก็บใน IndexedDB (ไฟล์ละไม่เกิน 15 MB) ของเบราว์เซอร์แต่ละเครื่อง
  ไม่ซิงก์ระหว่างเครื่องหรือผู้ใช้ การล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์อาจทำให้ข้อมูลหาย
- ยังไม่มีบัญชีผู้ใช้ ฐานข้อมูลส่วนกลาง สิทธิ์ตามบทบาท ประวัติการแก้ไข หรือการสำรองข้อมูลส่วนกลาง
  เหมาะสำหรับทดลองรูปแบบงาน หากให้ทีมรายงานผลบนข้อมูลชุดเดียวกันควรพัฒนาการจัดเก็บส่วนกลางก่อน
- ผังสร้างจากตำแหน่งข้อความใน Excel เส้นเชื่อม (เมื่อไม่มี connector ในไฟล์) ใช้การจับคู่กล่องที่ใกล้ที่สุด
  จึงไม่รับรองว่าตรงกับผังต้นฉบับทุกจุด การผูกระยะเวลากับกิจกรรมใช้แถวที่ใกล้ที่สุด อาจคลาดเคลื่อนในจุดที่วางไว้ระหว่างกล่อง
- ตารางยังไม่ได้นำรายการโครงการจากไฟล์ "แผนปฏิบัติการ กบค. 70.xlsx" เข้ามา หรือจับคู่เดือนกับกิจกรรม SIPOC อัตโนมัติ

## โครงสร้างไฟล์

```
index.html            หน้าจอหลัก
css/style.css         รูปแบบการแสดงผล (รองรับโหมดมืดและจอมือถือ)
js/sipoc-data.js      ข้อมูลตั้งต้น SIPOC (สร้างจาก tools/extract_sipoc.py)
Sipoc (SE-AM ...).xlsx  ไฟล์ SIPOC ต้นฉบับ 18 ไฟล์
js/store.js           การจัดเก็บ localStorage / IndexedDB
js/diagram.js         วาดผัง SIPOC เป็น SVG
js/app.js             มุมมอง ฟอร์ม รายงาน และการส่งออก
tools/extract_sipoc.py  ถอดข้อความจากไฟล์ Excel
```
